= Qualify a Governed VM Inference Fleet
:toc:

This 75–90 minute Showroom lab is separate from the seven-scene presentation. You will inspect a declared fleet, run baseline/migration/disruption qualification inputs, correlate placement and inference evidence, restart the adapter to prove ledger continuity, evaluate deterministic policy, and reclaim every candidate-owned resource.

The default is `REHEARSAL`. `LIVE` is permitted only when current-session OpenShift, KubeVirt, VM, migration, disruption, Intel CPU placement, inference execution, telemetry, and continuity evidence is directly observed.

The lab can recommend `ALLOW_REVIEW`, `REFUSE`, or `ABSTAIN`. It cannot certify, order, or promote anything.
