= 3. MIGRATE — 12 minutes

== Show

The migration trial compares a declared before/after service observation. The
adapter never initiates a migration.

== Learn

Destination placement alone is insufficient. Inference correlation and state
continuity must remain complete or the result is `ABSTAIN`.

== Do

[source,bash,role="execute"]
----
jq '.trials[] | select(.kind == "MIGRATION")' /tmp/fleet-qualified.json
----

== Prove

[source,bash,role="execute"]
----
jq -e '.trials[] | select(.kind == "MIGRATION") | .correlation_complete and .state_continuity' /tmp/fleet-qualified.json
----
